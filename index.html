System Monitor

Server and ResourceSpace statistics with live and history charts.

System Monitor shows on one page how the server and ResourceSpace are doing: CPU, memory, PHP-FPM, nginx and database processes, disk and network, together with active users, downloads, uploads and resources. A configuration check tells you which metrics are missing on your server and how to switch them on.

Features

Live view

CPU, memory, swap, load, PHP-FPM workers and queue, requests per second, database connections, network, disk I/O and active users, refreshed every few seconds with 10-minute charts.

Processes

Number, CPU and memory of PHP-FPM, nginx, the database, media processing (ImageMagick, ffmpeg, Ghostscript) and PHP CLI jobs.

Server history

Minute samples and hourly history from 6 hours to 1 year, average and maximum on every chart.

ResourceSpace statistics

Unique users, downloads, uploads, views, searches and logins per hour, day and month - including the time before the plugin was installed.

Resources and jobs

Resources by type and workflow state, files without previews, offline job queue with failed jobs, database size and top lists.

Widgets on every page

A side panel for chosen people and a compact header bar before the Upload button for whole user groups - Basic, Standard or Full set per group, numbers or small charts, a drop-down with more values.

Configuration check

PHP-FPM status, nginx stub_status, /proc and hidepid, database, OPcache and the cron collector - with ready-to-use configuration snippets.

Light

No cron needed: at most one sample per interval, taken after a page was sent. Reads /proc and status pages only - no shell commands.

Installation

In ResourceSpace

  1. Download the .zip above.
  2. In ResourceSpace open Plugin Manager > Upload a plugin and upload the file.
  3. Activate System Monitor in the list of installed plugins, then open its Options.

Updating: upload the new .zip and choose Overwrite. Settings and data are kept in the filestore, outside the plugin folder.

On the server (command line)

# download and unpack – <RS_ROOT> is your ResourceSpace folder
cd /tmp
curl -fLO https://github.com/s29829/system_monitor/releases/download/v1.01/system_monitor-1.01.zip
# only when updating – the plugin data stays in the filestore
sudo rm -rf <RS_ROOT>/plugins/system_monitor
sudo unzip -q system_monitor-1.01.zip -d <RS_ROOT>/plugins/
sudo chown -R www-data:www-data <RS_ROOT>/plugins/system_monitor

www-data is the user that runs PHP (Apache on the RHEL family: apache). Then activate the plugin in System > Plugins. With git: git clone https://github.com/s29829/system_monitor <RS_ROOT>/plugins/system_monitor

Requirements

  • ResourceSpace 11
  • Linux server for the server metrics (Ubuntu / Debian with nginx and PHP-FPM recommended)
  • PHP curl extension for the status pages
